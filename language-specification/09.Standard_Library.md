# 9. Standard Library

## 9.1 Overview

LLMK provides a standard library consisting of modules that define common TYPEs and FUNCTIONs.

Standard library modules shall be imported explicitly before they can be referenced.

Standard library modules follow the same module rules as user-defined modules.

The standard library is specified separately from this language specification.

The standard library provides the `Error` TYPE through the `Error` module.

---

## 9.2 Scope

The standard library includes functionality such as:

- String processing
- Array operations
- File system access
- JSON processing
- Date and time
- Math
- Networking
- Error handling utilities

The exact APIs are defined in the Standard Library Specification.

---

## 9.3 Language Independence

The language core shall be implementable independently of the standard library.

A compiler shall implement the language core regardless of the availability of standard library modules.

Standard library functionality shall not alter the syntax or semantics of the language core.

---

## 9.4 Design Principles

The standard library follows these principles.

- Minimal functionality.
- Stable interfaces.
- Strong backward compatibility.
- Explicit and predictable behavior.
- Consistent naming conventions.
- No hidden side effects.
